# BETTER Training App

Version 1 focuses on XC mountain bike race planning.

## Goal
Create a simple training planner that:
- Takes race dates
- Takes available days and hours
- Accounts for existing activities using fatigue points
- Generates a structured training calendar

## Project Structure
- index.html - Main application page
- css/styles.css - Visual design and colour system
- js/app.js - Planning logic
- docs/requirements.md - Functional requirements
- docs/training-algorithm.md - Planning algorithm design
- docs/fatigue-system.md - Fatigue system design

This version intentionally prioritises simplicity over advanced analytics.
