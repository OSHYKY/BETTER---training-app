# BETTER Requirements

## Version 1 Scope

### Inputs
- Target race date
- Available days
- Available hours
- Existing activities
- Fatigue points

### Outputs
- Weeks until race
- Training phase
- Training calendar (future)

### Design Goals
- Simplicity
- Fast setup
- XC MTB specific
- Expandable architecture

### Excluded Features
- Garmin integration
- AI coaching
- HRV analysis
- Nutrition planning
