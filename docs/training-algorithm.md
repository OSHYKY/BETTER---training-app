# Training Algorithm

## Inputs
1. Race Date
2. Available Days
3. Available Hours
4. Existing Activities

## Processing
1. Calculate weeks until race.
2. Determine training phase.
3. Generate suitable session types.
4. Check fatigue score.
5. Reduce load if fatigue threshold exceeded.
6. Display calendar.

## Phase Rules
12+ weeks = Base
6-12 weeks = Build
2-6 weeks = Race Specific
0-2 weeks = Taper
